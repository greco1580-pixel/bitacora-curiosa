# Imágenes de marca

Ilustraciones oficiales del Monstruito y otros elementos de marca.

- `hero-monstruito.png` — usada en `components/Hero.tsx`. Recomendado 1000x1250px (4:5).
- `sobre-monstruito.png` — usada en `app/sobre/page.tsx`. Recomendado 1200x800px (3:2).

Formato recomendado: PNG con transparencia, o JPG/WebP sobre textura de papel.

No generar ilustraciones nuevas del Monstruito sin las referencias oficiales:
reemplazar estos placeholders únicamente por arte real de la marca.
